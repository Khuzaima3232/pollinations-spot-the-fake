# Spot the fake

Two photographs of the same animal. One is a real photograph; one was generated by
AI. Pick the real one.

**Play it:** https://khuzaima3232.github.io/pollinations-spot-the-fake/

No sign-in, no API key, nothing to install. The fakes are generated ahead of time
and committed, so the game works for anyone who opens the link.

## Why it is more than a quiz

Most real-or-AI quizzes just tell you whether you were right. This one names the
specific tells that gave the fake away — glassy symmetrical eyes, paws with no
toes, snow with no footprints — so a player learns what to look for next time.
Each round carries its own tells.

The real photograph is credited and linked to its Wikipedia page.

## How the images were made

| Half | Source |
| --- | --- |
| Real | Lead photograph from a Wikipedia article, via `action=query&prop=pageimages&pithumbsize=1200`. Wikimedia hosts only freely-licensed media. |
| Fake | `black-forest-labs/flux.1-schnell` through Pollinations `POST /v1/images/generations` with `response_format: b64_json`. |

The model was chosen deliberately. The first attempt used a different model and
was rejected after inspecting the output: it had a malformed extra limb, glassy
eyes and painted-looking snow, which made the fake obvious at a glance. A puzzle
where the fake is instantly spottable is not a puzzle. `flux.1-schnell` was rated
a **medium-difficulty** fake on the same prompt — fooled at a glance, spottable on
inspection — which is the difficulty the game wants.

Regenerate the rounds with:

```sh
python build_rounds.py            # all subjects
python build_rounds.py --only fox --force   # one subject, regenerate
```

## Structure

```
index.html      the page
game.js         game logic (shuffling, verdicts, streak, localStorage)
rounds.json     the round data: image paths, credit, source, tells
rounds/         the committed images (real .jpg, fake .png)
build_rounds.py regenerates rounds/ and rounds.json from the API
test/           checks for the round data and the game logic
```

## Verification

```sh
node test/game.test.cjs
```

57 checks, all passing. They cover the round data (every image present on disk,
unique paths, every round credited and teaching at least three tells), the game
logic (the real image is not always in the same slot, a round is always one real
plus one fake, picking real is scored correct, picking fake is not, shuffle does
not mutate its input, a queue visits every round exactly once), and the wiring
between the page and the script.

Played through in a browser as well: a correct pick shows "Correct" and increments
the streak, a wrong pick resets it, the streak and best score persist in
`localStorage`, the next round resets the board, and the console reports no errors.

## Notes

- Images are 1200px-wide renders, ~220–260 KB each, so a round loads quickly.
- The game needs no backend. Serving the folder from any static host is enough.
- Fakes are labelled as such in `rounds.json`; the game shuffles them per round so
  the fake is not always in the same position.
